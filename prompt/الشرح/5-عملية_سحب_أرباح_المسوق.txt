================================================================================
                    عملية: سحب أرباح (عمولات) المسوق
================================================================================

📋 نظرة عامة:
--------------
عملية سحب المسوق لأرباحه (العمولات المتراكمة) تمر بعدة مراحل من إنشاء طلب السحب حتى التوثيق النهائي.
يتم صرف المبلغ للمسوق بعد موافقة الإدارة (Admin) وتوثيق الاستلام.

================================================================================
                        الحالات المتوقعة (Status Flow)
================================================================================

📌 الحالات الممكنة لطلب السحب:

1️⃣ pending (قيد الانتظار)
   - الحالة الأولية عند إنشاء طلب السحب
   - الطلب ينتظر موافقة الإدارة (Admin)
   - يمكن للمسوق إلغاؤه في هذه المرحلة

2️⃣ approved (موافق عليه)
   - الإدارة توافق على الطلب
   - يتم صرف المبلغ للمسوق
   - يتم رفع صورة إيصال الاستلام الموقع
   - لا يمكن التراجع بعد هذه المرحلة

3️⃣ rejected (مرفوض)
   - الإدارة ترفض الطلب
   - قد يكون بسبب عدم كفاية الرصيد أو أسباب إدارية
   - لا يتأثر رصيد المسوق


================================================================================
                    مخطط تدفق الحالات (Status Flow)
================================================================================

                            ┌─────────────┐
                            │   pending   │ ← إنشاء طلب السحب
                            └──────┬──────┘
                                   │
                         ┌─────────┴─────────┐
                         │                   │
                         ▼                   ▼
                   ┌──────────┐        ┌──────────┐
                   │ rejected │        │ approved │ ← الموافقة والصرف
                   └──────────┘        └──────────┘


================================================================================
                        المراحل والجداول المتأثرة
================================================================================

┌─────────────────────────────────────────────────────────────────────────────┐
│ المرحلة 1: إنشاء طلب السحب (Pending)                                       │
└─────────────────────────────────────────────────────────────────────────────┘

🔹 الفاعل: المسوق (Salesman/Marketer)
🔹 الشرط: يجب أن يكون هناك رصيد عمولات متاح للمسوق

📊 الجداول المتأثرة:
--------------------

1️⃣ marketer_withdrawal_requests
   - يتم إنشاء سجل جديد
   - الحقول المستخدمة:
     • id (تلقائي)
     • marketer_id (FK → users.id) - معرف المسوق
     • requested_amount (المبلغ المطلوب سحبه)
     • status = 'pending'
     • created_at (وقت الإنشاء)

📌 ملاحظة: في هذه المرحلة لا يتأثر رصيد العمولات


┌─────────────────────────────────────────────────────────────────────────────┐
│ المرحلة 2: رفض الإدارة (Rejected) - احتمال بديل                            │
└─────────────────────────────────────────────────────────────────────────────┘

🔹 الفاعل: الإدارة (Admin)
🔹 السبب: قد يكون بسبب عدم كفاية الرصيد أو أسباب إدارية أخرى

📊 الجداول المتأثرة:
--------------------

1️⃣ marketer_withdrawal_requests
   - تحديث السجل الموجود
   - الحقول المحدثة:
     • status = 'rejected'

📌 ملاحظة: لا يتأثر رصيد العمولات في حالة الرفض


┌─────────────────────────────────────────────────────────────────────────────┐
│ المرحلة 3: الموافقة والصرف (Approved)                                      │
└─────────────────────────────────────────────────────────────────────────────┘

🔹 الفاعل: الإدارة (Admin)
🔹 الشرط: يجب أن تكون الحالة 'pending' ورفع صورة إيصال الاستلام الموقع

📊 الجداول المتأثرة:
--------------------

1️⃣ marketer_withdrawal_requests
   - تحديث السجل الموجود
   - الحقول المحدثة:
     • status = 'approved'

2️⃣ marketer_withdrawals
   - إنشاء سجل جديد للسحب الموثق
   - الحقول المستخدمة:
     • id (تلقائي)
     • withdrawal_request_id (FK → marketer_withdrawal_requests.id)
     • marketer_id (FK → users.id)
     • amount (المبلغ المسحوب)
     • admin_id (FK → users.id) - معرف الإدارة الموافقة
     • signed_receipt_image (صورة إيصال الاستلام الموقع من المسوق)
     • confirmed_at (وقت التوثيق)

📌 ملاحظة: الآن فقط يتم صرف المبلغ وتوثيق العملية


================================================================================
                            ملخص الجداول المتأثرة
================================================================================

✅ جداول أساسية (تتأثر في كل الحالات):
   1. marketer_withdrawal_requests

✅ جداول السحوبات (تتأثر عند الموافقة فقط):
   2. marketer_withdrawals

✅ جداول مرجعية (للقراءة فقط):
   - users (للمسوق والإدارة)
   - marketer_commissions (لحساب الرصيد المتاح)


================================================================================
                        مخطط حركة الأموال
================================================================================

    ┌──────────────────────┐
    │ marketer_commissions │ ← العمولات المتراكمة للمسوق
    └──────────┬───────────┘
               │
               │ (حساب الرصيد المتاح)
               │ الرصيد = مجموع العمولات - مجموع السحوبات
               │
               ▼
    ┌──────────────────────┐
    │ withdrawal_request   │ ← طلب السحب (pending)
    └──────────┬───────────┘
               │
               │ (عند الموافقة - approved)
               │ (بعد رفع إيصال الاستلام الموقع)
               │
               ▼
    ┌──────────────────────┐
    │ marketer_withdrawals │ ← تسجيل السحب الموثق
    └──────────────────────┘


================================================================================
                            ملاحظات مهمة
================================================================================

⚠️ قواعد العمل:
   1. لا يمكن السحب بمبلغ أكبر من الرصيد المتاح للمسوق
   2. الرصيد المتاح = مجموع العمولات - مجموع السحوبات السابقة
   3. يجب رفع صورة إيصال الاستلام الموقع من المسوق عند الموافقة
   4. ⚠️ السحب لا يتم إلا عند الموافقة (approved)
   5. لا يمكن إلغاء طلب السحب بعد الموافقة عليه
   6. كل سحب يخصم من الرصيد المتاح للمسوق

🔐 الصلاحيات:
   - المسوق: إنشاء طلب السحب فقط
   - الإدارة (Admin): الموافقة، الرفض، رفع إيصال الاستلام

📊 التقارير المتاحة:
   - طلبات السحب حسب الحالة
   - سحوبات المسوق
   - رصيد العمولات المتاح
   - تاريخ السحوبات

💰 حساب الرصيد المتاح:
   - الرصيد المتاح = مجموع (marketer_commissions.commission_amount) - مجموع (marketer_withdrawals.amount)
   - يتم التحقق من الرصيد قبل الموافقة على طلب السحب
   - إذا كان المبلغ المطلوب > الرصيد المتاح، يتم رفض الطلب

💵 مصادر العمولات:
   - العمولات تأتي من تسديدات المتاجر (store_payments)
   - كل تسديد موثق يضيف عمولة للمسوق في marketer_commissions
   - العمولة = المبلغ المسدد × نسبة العمولة (users.commission_rate)

🔄 دورة العمولات:
   1. المتجر يسدد دين → تسجل عمولة للمسوق
   2. المسوق يطلب سحب → طلب pending
   3. الإدارة توافق → يتم الصرف وتوثيق السحب
   4. الرصيد المتاح ينخفض بمقدار المبلغ المسحوب

📝 إيصال الاستلام:
   - يجب أن يكون موقع من المسوق
   - يثبت استلام المسوق للمبلغ
   - يرفع من قبل الإدارة عند الموافقة
   - يحفظ في marketer_withdrawals.signed_receipt_image

🎯 أهداف النظام:
   - تحفيز المسوقين على تحصيل الديون
   - شفافية في حساب العمولات
   - توثيق كامل لكل عملية سحب
   - منع النزاعات المالية
