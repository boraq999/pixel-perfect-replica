================================================================================
                    عملية: طلب بضاعة من المسوق
================================================================================

📋 نظرة عامة:
--------------
عملية طلب المسوق للبضاعة من المخزن الرئيسي تمر بعدة مراحل من الإنشاء حتى التوثيق النهائي.

================================================================================
                        المراحل والجداول المتأثرة
================================================================================

┌─────────────────────────────────────────────────────────────────────────────┐
│ المرحلة 1: إنشاء الطلب (Pending)                                           │
└─────────────────────────────────────────────────────────────────────────────┘

🔹 الفاعل: المسوق (Salesman/Marketer)

📊 الجداول المتأثرة:
--------------------

1️⃣ marketer_requests
   - يتم إنشاء سجل جديد
   - الحقول المستخدمة:
     • id (تلقائي)
     • invoice_number (رقم الفاتورة)
     • marketer_id (معرف المسوق)
     • status = 'pending'
     • created_at (وقت الإنشاء)

2️⃣ marketer_request_items
   - يتم إضافة سجل لكل منتج في الطلب
   - الحقول المستخدمة:
     • id (تلقائي)
     • request_id (FK → marketer_requests.id)
     • product_id (FK → products.id)
     • quantity (الكمية المطلوبة)

3️⃣ marketer_request_status
   - يتم إنشاء سجل لحالة الطلب
   - الحقول المستخدمة:
     • id (تلقائي)
     • request_id (FK → marketer_requests.id)
     • marketer_id (FK → users.id)
     • keeper_id (NULL في البداية)
     • status = 'pending'
     • updated_at (وقت الإنشاء)

📌 ملاحظة: في هذه المرحلة لا يتأثر المخزن الرئيسي أو مخزون المسوق


┌─────────────────────────────────────────────────────────────────────────────┐
│ المرحلة 2: موافقة أمين المخزن (Approved)                                   │
└─────────────────────────────────────────────────────────────────────────────┘

🔹 الفاعل: أمين المخزن (Warehouse Keeper)

📊 الجداول المتأثرة:
--------------------

1️⃣ marketer_requests
   - تحديث السجل الموجود
   - الحقول المحدثة:
     • status = 'approved'

2️⃣ marketer_request_status
   - تحديث السجل الموجود
   - الحقول المحدثة:
     • keeper_id (FK → users.id) - معرف أمين المخزن
     • status = 'approved'
     • updated_at (وقت الموافقة)

📌 ملاحظة: في هذه المرحلة لا يتأثر أي مخزون، فقط الموافقة المبدئية


┌─────────────────────────────────────────────────────────────────────────────┐
│ المرحلة 3: رفض أمين المخزن (Rejected) - احتمال بديل                        │
└─────────────────────────────────────────────────────────────────────────────┘

🔹 الفاعل: أمين المخزن (Warehouse Keeper)

📊 الجداول المتأثرة:
--------------------

1️⃣ marketer_requests
   - تحديث السجل الموجود
   - الحقول المحدثة:
     • status = 'rejected'

2️⃣ marketer_request_status
   - تحديث السجل الموجود
   - الحقول المحدثة:
     • keeper_id (FK → users.id)
     • status = 'rejected'
     • updated_at

📌 ملاحظة: لا يتأثر المخزن في حالة الرفض


┌─────────────────────────────────────────────────────────────────────────────┐
│ المرحلة 4: إلغاء المسوق (Cancelled) - احتمال بديل                          │
└─────────────────────────────────────────────────────────────────────────────┘

🔹 الفاعل: المسوق (Salesman/Marketer)
🔹 الشرط: يمكن الإلغاء فقط إذا كانت الحالة 'pending'

📊 الجداول المتأثرة:
--------------------

1️⃣ marketer_requests
   - تحديث السجل الموجود
   - الحقول المحدثة:
     • status = 'cancelled'

2️⃣ marketer_request_status
   - تحديث السجل الموجود
   - الحقول المحدثة:
     • status = 'cancelled'
     • updated_at

📌 ملاحظة: لا يتأثر المخزن لأن الإلغاء يحدث قبل الموافقة


┌─────────────────────────────────────────────────────────────────────────────┐
│ المرحلة 5: توقيع المسوق واستلام البضاعة (Documented)                       │
└─────────────────────────────────────────────────────────────────────────────┘

🔹 الفاعل: المسوق (Salesman/Marketer) + أمين المخزن (Warehouse Keeper)
🔹 الشرط: يجب أن تكون الحالة 'approved'

📊 الجداول المتأثرة:
--------------------

1️⃣ marketer_requests
   - تحديث السجل الموجود
   - الحقول المحدثة:
     • status = 'documented'

2️⃣ delivery_confirmation
   - إنشاء سجل جديد للتوثيق
   - الحقول المستخدمة:
     • id (تلقائي)
     • request_id (FK → marketer_requests.id)
     • keeper_id (FK → users.id) - أمين المخزن
     • signed_image (صورة الفاتورة الموقعة)
     • status = 'documented'
     • confirmed_at (وقت التوثيق)

3️⃣ main_stock
   - خصم الكميات من المخزن الرئيسي
   - الحقول المحدثة:
     • quantity = quantity - الكمية_المطلوبة (لكل منتج)
     • updated_at (وقت التحديث)

4️⃣ marketer_actual_stock
   - إضافة أو تحديث الكميات في المخزون الفعلي للمسوق
   - الحقول المستخدمة:
     • id (تلقائي إذا كان سجل جديد)
     • marketer_id (FK → users.id)
     • product_id (FK → products.id)
     • quantity = quantity + الكمية_المطلوبة

5️⃣ warehouse_stock_logs
   - تسجيل حركة المخزن
   - الحقول المستخدمة:
     • id (تلقائي)
     • invoice_type = 'marketer_request'
     • invoice_id (معرف الطلب)
     • keeper_id (FK → users.id)
     • action = 'withdraw'
     • created_at

📌 ملاحظة: الآن فقط تتحرك البضاعة بعد رفع الفاتورة الموقعة


================================================================================
                            ملخص الجداول المتأثرة

✅ جداول أساسية (تتأثر في كل الحالات):
   1. marketer_requests

   7. delivery_confirmation

   - users (للمسوق وأمين المخزن)
   - products (لمعلومات المنتجات)

================================================================================
                            ملاحظات مهمة
================================================================================

⚠️ قواعد العمل:
   1. لا يمكن الموافقة على الطلب إذا كانت الكمية غير متوفرة في main_stock
   2. لا يمكن إلغاء الطلب بعد الموافقة عليه
   3. يجب رفع صورة الفاتورة الموقعة عند التوثيق
   4. ⚠️ البضاعة لا تتحرك إلا عند التوثيق (documented) وليس عند الموافقة
   5. البضاعة تنتقل من main_stock → marketer_actual_stock عند التوثيق فقط
   6. لا يوجد مخزون محجوز (reserved) في هذا النظام

🔐 الصلاحيات:
   - المسوق: إنشاء الطلب، الإلغاء (pending فقط), التوقيع
   - أمين المخزن: الموافقة، الرفض، التوثيق النهائي

📊 التقارير المتاحة:
   - طلبات المسوق حسب الحالة
   - حركة المخزون الرئيسي
   - مخزون المسوق (محجوز + فعلي)
   - سجل التوثيقات
